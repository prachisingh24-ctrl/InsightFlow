# InsightFlow

Feedback analysis platform for collecting and analyzing feedback, identifying recurring issues, generating insights and reports, and tracking action items.

## Project layout
- `apps/insightflow/` — primary app.
- `apps/insightflow-copy/` — additional app variant.
- `packages/components/` — shared UI components.

Run `npm install` from the repository root. Configure required environment variables locally; secret files are excluded. The original Zite project remains unchanged.
